main do C é a thread principal 

| Conceito    | Processo com `fork()`     | Thread com `pthread_create()`  |
| ----------- | ------------------------- | ------------------------------ |
| Cria        | Novo processo             | Nova thread                    |
| Memória     | Separada                  | Compartilhada                  |
| Comunicação | Mais difícil              | Mais simples                   |
| Custo       | Maior                     | Menor                          |
| Isolamento  | Maior                     | Menor                          |
| Exemplo     | Pai e filho independentes | Duas tarefas no mesmo programa |
